Bulk Order Multi-Step Mobile UI

Files:
- index.html
- style.css
- script.js

Flow implemented:
1. Search restaurant or food item.
   - Restaurant search opens that restaurant menu.
   - Food search shows nearest restaurants containing that item.
2. Select food items and units/quantity.
3. Select future delivery date/time.
   - Minimum date is tomorrow.
4. Use current location or add a new delivery address.
5. Add contact name, phone, and optional note.
6. Step 2 review with edit/remove and quantity controls.
7. Step 3 full billing, delivery info, contact info.
8. Razorpay-styled payment CTA.
9. Demo success/failure payment result screens.

Important:
This is a front-end prototype. Real geolocation, backend restaurant search, live distance sorting,
Razorpay checkout, database persistence, and real order creation must be connected in the app backend.
